# Python & Pandas Practical Test Solutions

This repository contains the complete dataset, python scripts, and outputs for the Python Lab Practical Test, featuring data manipulation with Pandas, numerical computing with NumPy, system file operations, and module architecture.

---

## 📁 Repository Structure

```text
.
├── employees.csv           # Base employee records dataset
├── heads.csv               # Department heads lookup dataset
├── names.json              # Exported employee JSON dataset (generated by script)
├── D_pandas_tasks.py       # Complete Pandas tasks script (Q11 - Q15)
├── c_numpy_tasks.py        # Complete NumPy tasks script (Q1 - Q10)
├── a_standard_modules.py   # Standard library modules (datetime, math, random, uuid, time)
├── B_os_demo.py            # OS & Shutil file management tasks
├── b_main_package.py       # Custom package import demonstration
├── datetools.py            # Custom module with leap year & date helpers
└── README.md               # Project documentation
```

## 🚀 Execution & Usage

### Running the Pandas Script (`D_pandas_tasks.py`)
Ensure `pandas` is installed in your environment:
```bash
pip install pandas
python D_pandas_tasks.py
```

## 📋 Section D: Pandas Summary (Q11 - Q15)

| Question | Topic / Tasks | Key Operations |
| :--- | :--- | :--- |
| **Q11** | Series, DataFrames & Exploration | `pd.Series`, `iloc`, `pd.read_csv()`, `df.duplicated()`, `df.isna()` |
| **Q12** | Data Cleaning & Data Types | `drop_duplicates()`, `pd.to_numeric()`, `fillna()`, `pd.to_datetime()`, `.dt.year` |
| **Q13** | Column Creation, Filtering & Binning | Boolean indexing (`&`), `apply()`, `pd.Categorical`, `sort_values()`, `value_counts()` |
| **Q14** | Aggregations & Pivot Tables | `groupby().agg()`, `transform('sum')`, `pivot_table()` |
| **Q15** | Merges, Indexing & JSON IO | `pd.merge()` (left/inner/outer), `set_index()`, `loc`, `to_json()`, `read_json()` |
